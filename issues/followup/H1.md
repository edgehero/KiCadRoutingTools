**What happens**

A mounting hole gets only the ordinary hole/pad clearance. Nothing models the screw head, washer, nut or standoff that sits around it. Where the hole's footprint draws no keep-out ring of its own, route.py lays tracks up to it, and nothing reports it:
- KiCad DRC checks hole_clearance only (0.25 mm);
- the repo's checkers and the placement verifier pass these boards.

**Reproduce** (only this repository, KiCad 10 and about a minute; checked in a clean checkout of main 0c05be08, and the same at bda59fa0 and under two `PYTHONHASHSEED` values)

Save the script below as `hole_copper.py` in the repository root, then run:
```
python3 -X utf8 hole_copper.py kicad_files/tigard.kicad_pcb
#   as designed: H1-H4 (MountingHole_3.2mm_M3_ISO7380) -- 0 other-net items within 1.3 mm of the hole edge
python3 -X utf8 tests/stress/strip_copper_only.py kicad_files/tigard.kicad_pcb /tmp/tigard_bare.kicad_pcb
python3 -X utf8 py_router/route.py /tmp/tigard_bare.kicad_pcb /tmp/tigard_routed.kicad_pcb --nets '*'
python3 -X utf8 hole_copper.py /tmp/tigard_routed.kicad_pcb
#   H4: 5 other-net items within 1.3 mm of the hole edge, /ICE_CDONE (F.Cu) 0.65 mm and /CIPO (B.Cu) 0.75 mm from it
```
1.3 mm past the hole edge is about the footprint of an ISO 7380 M3 head; a washer or a standoff reaches further. On the same board's own layout the designer kept every hole clear.

<details><summary><code>hole_copper.py</code></summary>

```python
#!/usr/bin/env python3
"""Other-net copper around each mounting hole of one board (the screw head / washer / standoff area).

    python3 -X utf8 hole_copper.py BOARD.kicad_pcb [--ring 1.3]     (from the repository root)

A mounting hole = a footprint with <= 9 pads whose pads ALL carry a drill >= 2.0 mm and no signal net (none,
`unconnected-*`, or a GND-named net). For each one: the drill, the plated pad's diameter, and every track, arc
and via of another net whose copper comes within RING mm of the hole edge (default 1.3 mm, about an ISO 7380
M3 head; a washer reaches further), with its distance to the pad copper.
"""
import math
import os
import re
import sys

sys.path.insert(0, os.path.join(os.getcwd(), 'py_router'))
from kicad_parser import parse_kicad_pcb  # noqa: E402

board = sys.argv[1]
RING = float(sys.argv[sys.argv.index('--ring') + 1]) if '--ring' in sys.argv else 1.3
pcb = parse_kicad_pcb(board)
for ref, f in sorted(pcb.footprints.items()):
    pads = f.pads
    if not pads or len(pads) > 9 or not all(p.drill and p.drill >= 2.0 for p in pads):
        continue
    if any(p.net_name and not re.match(r'(unconnected-|.*GND)', p.net_name, re.I) for p in pads):
        continue
    d = max(p.drill for p in pads)
    pr = max(max(p.size_x, p.size_y) for p in pads) / 2 if any(p.pad_type == 'thru_hole' for p in pads) else d / 2
    own = {p.net_id for p in pads if p.net_id}
    hits = []
    for s in pcb.segments:
        if getattr(s, 'graphic', False) or s.net_id in own:
            continue
        ax, ay, bx, by = s.start_x, s.start_y, s.end_x, s.end_y
        L2 = (bx - ax) ** 2 + (by - ay) ** 2
        t = 0 if L2 == 0 else max(0, min(1, ((f.x - ax) * (bx - ax) + (f.y - ay) * (by - ay)) / L2))
        g = math.hypot(ax + t * (bx - ax) - f.x, ay + t * (by - ay) - f.y) - s.width / 2
        if g < d / 2 + RING:
            hits.append((round(g - pr, 2), s.layer, pcb.nets[s.net_id].name if s.net_id in pcb.nets else s.net_id))
    for v in pcb.vias:
        g = math.hypot(v.x - f.x, v.y - f.y) - v.size / 2
        if v.net_id not in own and g < d / 2 + RING:
            hits.append((round(g - pr, 2), 'via', pcb.nets[v.net_id].name if v.net_id in pcb.nets else v.net_id))
    hits.sort()
    nets = sorted({h[2] for h in hits})
    print(f'{ref} {f.footprint_name.split(":")[-1]}: drill {d}, pad dia {2 * pr:.2f}; {len(hits)} other-net items within '
          f'{RING} mm of the hole edge; closest to the pad copper (mm, layer, net): {hits[:3]}; nets {nets[:6]}')
```

**The same on the gpm boards** (for context; the test above needs nothing else)

| board | hole | items within 1.3 mm, human → delivered | closest |
|---|---|---|---|
| icebreaker_v10e | 5 of 6 unplated M3 holes (no courtyard) | 0-1 each → up to 23 | `/FLASH_MOSI\|IO0`, `+5V` 0.25 mm from the hole edge |
| CM5_MINIMA_3 | M701 / M702, the M.2 card standoffs (4.5 mm plated pads) | 0 / 1 → 35 / 31 | `+5V`, `VBUS_USB2.0`, `/CC2`, I2C 0.10 mm from the pad |

33 of those 43 holes were clean, mostly the ones whose footprint's courtyard reaches well past the pad.

**What exists.** `py_router/add_rule_area.py` (#1200) writes a copper keep-out, relative to a footprint with `--ref`. Nothing calls it for mounting holes, and neither skill asks for it. A design-brief `keepouts[]` still reaches placement only.

**Expected**
- Derive a copper keep-out ring per mounting hole on both faces, sized from its screw (from the footprint name or the drill: head or washer diameter plus a margin). `floorplan.derived_mating_keepouts` already derives keep-outs this way for PCB-edge plugs.
- route.py, route_planes and the plane finalize honour that ring, as they honour a rule area.
- board_score / check_complete grade it.
- A declared override stays possible: a designer may want a GND ring under a plated hole.
